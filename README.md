# VAIZO — paper peel first-view prototype

「AIを、事業を変える力に。」を使ったVAIZOのFV検討用プロトタイプです。

プレビュー: https://isseimasuya.github.io/vaizo-fv-paper-peel/

## 実装範囲

- HTMLの文字組み・レスポンシブ配置。ページ全体を画像にした実装ではありません。
- AI生成の写真アトラスと、透過の紙テクスチャ。
- Canvas 2Dによる紙の曲面変形。紙をめくり、下の写真を順番に表示します。
- 初回に一度だけ自動再生。「もう一度めくる」で再生できます。
- OSの「視差効果を減らす」設定では、動かさず写真を表示します。
- FV直後には、スクロール確認用の3事業への小さな導線を設置しています。下層ページ全体の実装ではありません。

## 起動

Node.js 18以降で、依存パッケージのインストールなしで動作します。

```sh
npm run dev
```

http://127.0.0.1:4173 を開いてください。静的ファイルなのでGitHub Pagesでもそのまま配信できます。

## ファイル

- `index.html`: 構成・コピー・実サイトへの導線
- `styles.css`: PC/タブレット/スマートフォンのレイアウト
- `peel.js`: ラスター紙テクスチャの変形・アニメーション
- `assets/photos.png`: 画像生成による3カットの写真アトラス
- `assets/paper.png`: 画像生成による紙テクスチャと透過エッジ
- `serve.mjs`: 依存なしのローカル確認サーバー

## 素材と状態

写真と紙は本プロトタイプ用に内蔵画像生成ツールで生成しました。実在のVAIZOメンバー、導入先、製品の写真を示すものではありません。ベクターイラストは使用していません。紙の曲面表現はラスター素材をCanvas上で変形しています。

ロゴはテキストによる仮のワードマークです。正式ロゴの入稿データへ差し替える前の検討版です。Google FontsのNoto Sans JP / Noto Serif JPを使用し、ネットワークが使えない場合は端末の日本語書体へフォールバックします。

デザイン・構成は未承認の検討案です。本番サイトを変更しません。リンク先は公式サイトです。`noindex,nofollow`を設定していますが、ソース・画像はpublicリポジトリとして公開されます。フォーム送信・解析・Cookieはありません。
